# devlog

크래프톤 정글 하루 한 장 모션 카드예요. GitHub Pages 에 올리는 걸 전제로 만들었어요.

## 카드 두 종류

| 종류 | 쓰는 날 | 장면 |
|---|---|---|
| 버그 (`bug`) | 버그를 잡은 날 | 증상 → 원인 → 고침. 문제 줄의 이름표가 선을 따라 코드 자리로 갔다가, 고친 뒤 초록으로 돌아와요 |
| 숫자 (`numbers`) | 그 밖의 날 | 전체 실행 결과가 단계마다 바뀌어요. 바뀐 칸만 다시 칠해져요 |

화면에 들어오면 한 번 재생되고, `다시 보기` 와 단계 버튼으로 다시 볼 수 있어요.

## 폴더

- `assets/` 공용 스타일과 모션
- `templates/` 새 카드를 만들 때 복사하는 틀
- `days/` 날짜별 카드
- `days.js` 목록에 보일 날짜

## 미리 보기

`file://` 로 열어도 돌아가요. 폰트만 인터넷에서 받아요.
